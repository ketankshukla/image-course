# Verification scope

The repository/deployment guide is an architectural proposal, not a scaffold or deployment.

The HTML edition embeds its two SVG diagrams, stylesheet, and interaction script. Verification checks document structure, image embedding, internal navigation, SVG XML, and JavaScript syntax. Browser interaction and responsive layout are not certified by these static checks.

The two diagrams are code-authored SVGs for precise labels and repository mappings; no image-generation tool was needed. The existing reading template and styling are reused.

Rebuild from any working directory by invoking this folder's `rebuild.ps1`.
